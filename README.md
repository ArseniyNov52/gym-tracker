## 📖 О проекте

**GymFlow** — это лёгкое и мощное приложение для тренировок, которое работает прямо в браузере без установки и регистрации. Все данные хранятся локально на вашем устройстве (localStorage), что обеспечивает полную конфиденциальность и работу офлайн.

Приложение создано для тех, кто хочет:
- 📊 Отслеживать прогресс в силовых тренировках
- ⏱️ Контролировать время отдыха между подходами
- 🎯 Ставить и достигать целей
- 🏆 Получать мотивацию через систему достижений
- 📈 Анализировать статистику и динамику результатов

## ✨ Возможности

### 🏋️ Тренировки
- **Свободные тренировки** — начните в любой момент и добавляйте упражнения на ходу
- **Шаблоны тренировок** — создавайте и переиспользуйте готовые программы
- **Учёт подходов** — вес, повторения и самочувствие для каждого подхода
- **Быстрое добавление** — кнопка «Как предыдущий» для повторения последнего подхода
- **Вес тела** — фиксация до и после тренировки
- **Заметки** — записывайте ощущения и идеи по тренировке

### ⏱️ Таймеры
- **Основной таймер тренировки** — продолжает работать в фоновом режиме (даже при блокировке экрана)
- **Таймер отдыха между подходами** — настраивается индивидуально для каждого упражнения
- **Быстрый таймер** — предустановки на 1, 1.5, 2, 3 и 5 минут

### 📊 Статистика и аналитика
- **Общая статистика** — количество тренировок, подходов, тоннаж, время в зале
- **Графики прогресса** — рост рабочего веса и тоннажа по каждому упражнению
- **Динамика веса тела** — отслеживание изменений до/после тренировок
- **График самочувствия** — визуализация настроения с эмодзи
- **Интерактивные SVG-графики** — адаптированы под мобильные устройства

### 🎯 Цели и достижения
- **Личные цели** — устанавливайте цели с прогресс-баром и обновляйте результаты
- **24 достижения** в 4 категориях:
  - 🏅 Постоянство (1 → 800 тренировок)
  - 🏋️ Вес на тренировках (1 → 40 тонн за раз)
  - 🏭 Общий тоннаж (50 → 1000 тонн)
  - ⏰ Время в зале (5 → 500 часов)

### 📅 Календарь посещений
- Визуальный календарь с отметками тренировок
- Месячная статистика по количеству тренировок и тоннажу

### 💾 Управление данными
- **Экспорт данных** в JSON-файл (резервная копия)
- **Импорт данных** из резервной копии
- **Полный сброс** с предварительным экспортом
- Всё хранится локально — **никаких серверов, никакой регистрации**

### 📤 Поделиться результатами
- Экспорт тренировки в текстовом формате
- Экспорт общей статистики
- Копирование в буфер обмена одним кликом

### 📱 Адаптивность
- Полностью адаптивный интерфейс (mobile-first)
- Крупные кнопки и элементы управления (44px+) для удобства на телефоне
- Оптимизация под сенсорные экраны
- Поддержка «холодного старта» с восстановлением активной тренировки

## 📱 Использование

### Начало тренировки
1. Откройте вкладку **💪 Тренировка**
2. Нажмите **«Начать тренировку»** или выберите шаблон
3. Добавьте упражнения через кнопку **➕ Упражнение**
4. Записывайте подходы, указывая вес, повторения и самочувствие
5. По завершении нажмите **✅ Завершить тренировку**

### Создание шаблона
1. Перейдите в **📅 Шаблоны** → **➕ Создать шаблон**
2. Укажите название и выберите упражнения
3. При необходимости задайте время отдыха для каждого упражнения (⏱️)
4. Сохраните — шаблон готов к использованию

### Анализ прогресса
1. Откройте **📊 Статистика**
2. Выберите упражнение в выпадающем списке
3. Изучайте графики роста рабочего веса и тоннажа
4. Просматривайте динамику веса тела и самочувствия

## 🧰 Технологии

| Технология | Назначение |
|------------|-----------|
| **React 18** | UI-библиотека (UMD-сборка) |
| **Babel Standalone** | Транспиляция JSX прямо в браузере |
| **Vanilla CSS** | Стилизация без фреймворков |
| **localStorage** | Локальное хранение данных |
| **SVG** | Кастомные графики без внешних библиотек |
| **Google Analytics** | Аналитика использования |

**Особенности реализации:**
- ⚡ Один файл — zero-build, работает без сборки
- 🎨 Дизайн в стиле современных SaaS-приложений (gradient, glassmorphism)
- 🔒 Все данные остаются на устройстве пользователя
- 🌐 Работает офлайн после первой загрузки

```

└── index.html          # Всё приложение в одном файле
    ├── <style>         # Стили (адаптивные, mobile-first)

        ├── DualLineChart      # Двойной график
        ├── MoodChart          # График настроения
```
